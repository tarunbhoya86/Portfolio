# Tarun Bhoya - Modern Developer & Designer Portfolio

A sleek, modern, and responsive personal portfolio website built with HTML5, Vanilla CSS, and JavaScript.

🌐 **Live Demo:** [https://online-learning-bay.vercel.app/](https://online-learning-bay.vercel.app/)

---

## ✨ Features

- **Responsive Design:** Seamless experience across desktop, tablet, and mobile devices.
- **Hero Section:** High-impact introduction with custom hexagon branding and interactive social links.
- **About Me Section:** 2x2 grid highlighting core skills in Web Development, App Development, UI/UX Design, and Mentorship.
- **Featured Projects:** Showcases portfolio projects including Full Stack AI platforms with direct live demo links.
- **Resume Section:** Instant in-browser PDF viewer and direct resume download.
- **Modern Dark Aesthetic:** Emerald glow accents, smooth micro-interactions, and custom typography with Google Fonts (*Poppins*).
- **Navigation Scroll-Spy:** Real-time section tracking and active link indicators.

---

## 🛠️ Tech Stack

- **Markup & Structure:** HTML5
- **Styling:** Vanilla CSS3 (Custom design system, flexbox, CSS grid, media queries)
- **Interactivity:** Modern Vanilla JavaScript (ES6+)
- **Icons:** Font Awesome 6
- **Typography:** Google Fonts (Poppins)

## 🚀 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/tarunbhoya86/Portfolio.git
   ```

2. **Navigate to the directory:**
   ```bash
   cd Portfolio
   ```

3. **Open in browser:**
   Open `index.html` in your favorite web browser or run a local server:
   ```bash
   npx serve .
   ```
